# Rotary A4 Agenda — Editable Template

A reusable, Rotary-branded **A4** document template (5 pages) rebuilt from the
"New Member Onboarding" layout. All copy has been replaced with placeholder text
(`Here goes your text` / `lorem ipsum`) and generic labels so anyone can drop in
new content without rebuilding the design.

## Files

| File | Use it in | Notes |
|------|-----------|-------|
| `Rotary_A4_Agenda_Template.docx` | **Microsoft Word** and **Google Docs** | One file works in both. In Google Docs: *File → Open → Upload*. Fully editable text, colors, and tables. |
| `Rotary_A4_Agenda_Template_PREVIEW.pdf` | **Canva** (import) & printing | In Canva: *Create a design → Import file* → pick this PDF to get an editable Canva design. Also the print-ready reference. |
| `Rotary_A4_Agenda_Template_preview.html` | Browser preview | Self-contained (fonts + logo embedded). Open to see the exact design. |
| `assets/rotary-wheel.png` | Logo mark | Transparent gold Rotary wheel used in the header. |

## Design system

- **Format:** A4 portrait, 5 pages
- **Colors:** Royal Blue `#17458F` · Gold `#F7A81B` · Azure `#0067C8` · Card `#F2F6FC` · Border `#E3E8EF` · Cream `#FFFAF0`
- **Fonts:** Headings *Oswald* (condensed), body *Open Sans* — both free Google Fonts, native in Google Docs. Word substitutes gracefully if not installed.

## Page map

1. **Cover** — brand row, blue hero title block, "Before You Begin" 4-card grid, "The Path" flow diagram, blue + cream callouts.
2. **Step One** — step bar, numbered items, bullet list, emphasis callout, "Before Moving On" box.
3. **Step Two + Step Three** — two step bars with numbered items.
4. **Final Check** — three check cards, "Remember" box, tag/pill grid, closing section.
5. **Quick Reference** — flow diagram, numbered quick-reference box, closing blue block, byline.

## How to rebrand

Replace `Your Club Name Here`, `Category Here`, `Section Title Here`, `Main Title Here`,
the `Keyword · Keyword · Keyword` strings, and every `Here goes your text` / `Lorem ipsum`
block with your own copy. Swap `assets/rotary-wheel.png` for your club's logo if desired.
